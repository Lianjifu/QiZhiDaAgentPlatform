# 06 · 接口规范（RESTful · SSE · MCP Tool 协议 · DTO 类型契约 · Error Code）

> 前端与后端 Enterprise-Agent-OS 的契约：
> - **RESTful** 严格状态码（与后端 `06-接口规范` 平行）
> - **SSE** Turn 流式协议
> - **MCP** Tool 协议（前端在 tool_call 渲染时使用）

> **基于 docs/web-refactor/06-组件分层.md + 07-状态管理.md 模板**。
> 与原模板差异：聚焦前端视角的接口契约（REST + SSE + MCP）；DTO 来自后端 OpenAPI Codegen；Error Code 镜像后端业务错误码；与后端 `docs/qizhida-agent-platform/06-接口规范.md` 平行阅读。

## 6.1 总体契约

| 类别 | 协议 | 传输 |
|---|---|---|
| **RESTful** | HTTP/1.1 + JSON | `@qzdap/web-api` ApiClient |
| **SSE** | text/event-stream | `@qzdap/web-api` ApiClient.stream |
| **MCP Tool** | JSON-RPC over SSE | tool BC 适配器 |

## 6.2 RESTful 严格状态码（与后端对齐）

### 6.2.1 状态码使用

| 状态码 | 含义 | 前端处理 |
|---|---|---|
| **200** | 成功 | 正常 |
| **201** | 创建成功 | 正常 |
| **204** | 删除成功（无 body） | 正常 |
| **400** | 请求格式错误 | 表单错误提示 |
| **401** | 未认证 | 跳转 /login |
| **403** | 无权限 | 跳转 /403 |
| **404** | 资源不存在 | 空状态 |
| **409** | 资源冲突 | 业务提示 |
| **422** | 业务校验失败 | 表单字段错误 |
| **429** | 限流 | 重试（指数退避） |
| **500** | 服务器错误 | 通用错误页 |
| **502** | 网关错误 | 重试 |
| **503** | 服务不可用 | 降级（切 MockApiAdapter） |

### 6.2.2 前端错误映射

```ts
// packages/api/src/errors.ts
export class ApiError extends Error {
  constructor(
    public readonly status: number,
    public readonly code: string,
    public readonly detail: unknown,
  ) {
    super(`${status} ${code}`);
  }
}

export function mapStatusToError(status: number, body: unknown): ApiError {
  const code = (body as { code?: string })?.code ?? 'UNKNOWN';
  const detail = (body as { detail?: unknown })?.detail ?? body;
  return new ApiError(status, code, detail);
}
```

### 6.3.4 前端 SSE 客户端

```ts
// packages/api/src/client.ts（已在 03-共享内核 3.3.2 给出）
async *stream(opts: { method: 'POST'; path: string; body?: unknown; signal?: AbortSignal }): AsyncIterable<unknown> {
  const res = await this.fetchStream(opts);
  const reader = res.body!.getReader();
  const decoder = new TextDecoder();
  let buffer = '';
  while (true) {
    const { value, done } = await reader.read();
    if (done) break;
    buffer += decoder.decode(value, { stream: true });
    const lines = buffer.split('\n\n');
    buffer = lines.pop() ?? '';
    for (const line of lines) {
      if (line.startsWith('data:')) {
        const payload = line.slice(5).trim();
        if (payload && payload !== '[DONE]') yield JSON.parse(payload);
      }
    }
  }
}
```

### 6.3.5 前端 chunk 渲染分支

```tsx
// features/session/ui/components/TurnNarrative.tsx
import type { TurnChunkDTO } from '@qzdap/web-types';

export function TurnNarrative({ chunks }: { chunks: readonly TurnChunkDTO[] }) {
  return (
    <>
      {chunks.map((chunk, i) => (
        <ChunkRenderer key={i} chunk={chunk} />
      ))}
    </>
  );
}

function ChunkRenderer({ chunk }: { chunk: TurnChunkDTO }) {
  switch (chunk.type) {
    case 'message':
      return <p>{chunk.delta}</p>;
    case 'tool_call':
      return <ToolCallCard toolName={chunk.tool_name} args={chunk.args} status="running" />;
    case 'tool_result':
      return <ToolCallCard toolName="..." result={chunk.result} status="completed" />;
    case 'skill_invocation':
      return <SkillInvocationCard skillName={chunk.skill_name} status={chunk.status} />;
    case 'memory_write':
      return <MemoryWriteBadge memoryType={chunk.memory_type} />;
    case 'knowledge_search':
      return <KnowledgeSearchBadge query={chunk.query} hits={chunk.hits} />;
    case 'usage':
      return <UsageBadge input={chunk.input} output={chunk.output} />;
    case 'done':
      return <TurnCompleteBadge usage={chunk.usage} />;
    case 'error':
      return <ErrorBadge code={chunk.code} message={chunk.message} />;
  }
}
```

### 6.5.3 DTO ↔ Entity 转换

```ts
// features/session/model/entities/Session.ts
import type { SessionDTO } from '@qzdap/web-types';
import { SessionId } from '../value-objects/SessionId';
import { Turn } from './Turn';

export class Session {
  static fromDTO(dto: SessionDTO): Session {
    const s = new Session(
      new SessionId(dto.id),
      dto.agent_version_id,
      dto.workspace_id,
    );
    if (dto.status === 'closed') s.close();
    dto.turns.forEach(t => s.appendTurn(Turn.fromDTO(t)));
    return s;
  }
  toDTO(): SessionDTO {
    return {
      id: this._id.value,
      agent_version_id: this._agentVersionId,
      workspace_id: this._workspaceId,
      status: this._status,
      created_at: '',
      closed_at: null,
      turns: this._turns.map(t => t.toDTO()),
      metadata: {},
    };
  }
}
```

## 6.6 认证头与 Tenant / Workspace 头

### 6.6.1 必备头

| 头 | 来源 | 说明 |
|---|---|---|
| `Authorization` | auth.store.token | `Bearer {token}` |
| `X-Tenant-Id` | tenant.store.current | 租户 ID |
| `X-Workspace-Id` | workspace.store.current | 工作区 ID |
| `X-Trace-Id` | traceContext.get | 当前 trace_id |
| `Content-Type` | ApiClient | `application/json` |
| `Accept` | ApiClient | `application/json` 或 `text/event-stream` |

### 6.6.2 ApiClient 注入

```ts
// packages/api/src/client.ts
async request<T>(opts: { ... }): Promise<T> {
  const headers: Record<string, string> = {
    'Content-Type': 'application/json',
    ...opts.headers,
  };
  const token = this.config.getToken();
  if (token) headers['Authorization'] = `Bearer ${token}`;
  const tenantId = this.config.getTenantId();
  if (tenantId) headers['X-Tenant-Id'] = tenantId;
  const workspaceId = this.config.getWorkspaceId();
  if (workspaceId) headers['X-Workspace-Id'] = workspaceId;
  const traceId = traceContext.get();
  if (traceId) headers['X-Trace-Id'] = traceId;
  // ...
}
```
