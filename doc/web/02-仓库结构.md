# 02 · 仓库结构（pnpm Workspace · FSD 6 层 · 8 BC 4 子目录）

> 物理骨架：qizhida-agent-platform/web/
> packages/* （shared，6 个）+ web/src/{app,pages,widgets,features,entities}（FSD 切片）
> 8 BC × features/<bc>/{model,lib,api,ui}
> ESLint + import-linter 守 FSD 单向依赖
> 与后端 qizhida-agent-platform/ 同仓库独立目录

> **基于 docs/web-refactor/02-仓库结构.md 模板**。
> 与原模板差异：BC 名对齐后端 modules/（agent_runtime / session / skill / tool / knowledge / memory / governance / identity）；新增 channel 前端独有 BC；新增 observability 横切 widgets；path alias 前缀 `@qzdap/*`（区分老 `@de/*`）。

## 2.6 FSD 单向依赖矩阵（强制）

| 层 ↓ → | app | pages | widgets | features | entities | shared |
|---|---|---|---|---|---|---|
| **app** | — | ✅ | ✅ | ✅ | ✅ | ✅ |
| **pages** | ❌ | — | ✅ | ✅ | ✅ | ✅ |
| **widgets** | ❌ | ❌ | — | ✅ | ✅ | ✅ |
| **features** | ❌ | ❌ | ❌ | —（同 BC） | ✅ | ✅ |
| **entities** | ❌ | ❌ | ❌ | ❌ | — | ✅ |
| **shared** | ❌ | ❌ | ❌ | ❌ | ❌ | — |

> **强约束**：每个层只可依赖其下方的层；同层仅可引用同 BC 或共享的 entities。

## 2.7 BC 内部依赖矩阵（FSD × Hex）

| ← 被依赖 \ → 依赖 | model | lib | api | ui |
|---|---|---|---|---|
| **model** | — | ❌ | ❌ | ❌ |
| **lib** | ✅（仅同 BC） | —（同 BC） | ❌ | ❌ |
| **api** | ✅（同 BC） | ✅（同 BC） | —（同 BC） | ❌ |
| **ui** | ✅（同 BC） | ✅（同 BC） | ✅（同 BC） | —（同 BC） |

> **model 永远不依赖 lib / api / ui**——这是 Hex 核心 + DDD 核心的根本。

## 2.9 import-linter 二次守门（CI 必跑）

```bash
# web/scripts/check-fsd-imports.sh
#!/usr/bin/env bash
set -e
ERRORS=0

# 1. pages 不能 import model/lib
if grep -rEn "from ['\"]@/features/[a-z]+/(model|lib)" src/pages/; then
  echo "❌ FSD violation: src/pages/* imports features/<bc>/{model,lib}"
  ERRORS=1
fi

# 2. features 不能 import widgets/pages/app
if grep -rEn "from ['\"]@/(widgets|pages|app)" src/features/; then
  echo "❌ FSD violation: features/* imports @/widgets or @/pages or @/app"
  ERRORS=1
fi

# 3. features 不能 import 其他 BC 的 model/lib
for bc in agent_runtime session skill tool knowledge memory governance identity channel; do
  OTHER_BC_DIRS=$(ls src/features/ | grep -v "^$bc$" | tr '\n' '|')
  if grep -rEn "from ['\"]@/features/(${OTHER_BC_DIRS%|})/(model|lib)" src/features/$bc/ 2>/dev/null; then
    echo "❌ FSD violation: features/$bc/ imports other BC's model/lib"
    ERRORS=1
  fi
done

# 4. 业务代码禁止 import @qzdap/web-mock
if grep -rEn "from ['\"]@qzdap/web-mock" src/features/ src/widgets/ src/pages/; then
  echo "❌ Hex violation: business code imports @qzdap/web-mock"
  ERRORS=1
fi

# 5. model 不应 import react / zustand / react-query
if grep -rEn "(from ['\"]react|from ['\"]zustand|from ['\"]@tanstack/react-query)" src/features/*/model/; then
  echo "❌ Hex violation: model/ imports react/zustand/react-query"
  ERRORS=1
fi

exit $ERRORS
```

```jsonc
// web/package.json
{
  "scripts": {
    "lint": "eslint .",
    "lint:fsd": "bash scripts/check-fsd-imports.sh",
    "ci:guard": "pnpm typecheck && pnpm lint && pnpm lint:fsd"
  }
}
```
