### 4.3.4 `memory` 长期记忆 ⭐

**状态**：P4 ✅ 已完成（122 测试通过 / 覆盖 P4-1~P4-10）。Bench: 10k 行 P95=3.66ms（目标 ≤ 200ms）。

**职责**：记忆条目 CRUD、向量索引、检索、撤销、过期清理；接入 `agent_runtime` turn 开头 recall。

**领域对象**：

```python
@dataclass(slots=True, frozen=True)
class MemoryEntry:
    id: MemoryEntryId
    tenant_id: TenantId
    workspace_id: WorkspaceId
    owner_id: UserId
    scope: MemoryScope                # 'user' / 'agent' / 'workspace'
    content: str
    metadata: dict[str, Any]
    embedding: tuple[float, ...]      # len == 1536
    revoked: bool = False
    version_lock: int = 1
    expires_at: datetime | None
    created_at: datetime
    updated_at: datetime
```

> `revoked = True` 表示软删；查询过滤 `revoked == False`。`expires_at <= now()` 自动隐藏。

**关键端口**：

```python
class EmbeddingPort(Protocol):
    async def embed(self, texts: list[str]) -> list[list[float]]: ...

class MemoryRepository(Protocol):
    async def add(self, entry: MemoryEntry) -> None: ...
    async def get(self, *, tenant_id, memory_id) -> MemoryEntry | None: ...
    async def list(self, *, tenant_id, workspace_id, scope=None, limit=50) -> list[MemoryEntry]: ...
    async def revoke(self, *, tenant_id, memory_id) -> MemoryEntry: ...
    async def purge_expired(self, *, tenant_id, now) -> int: ...

class VectorSearchPort(Protocol):
    async def upsert(self, *, tenant_id, workspace_id, memory_id, embedding, scope=None) -> None: ...
    async def search(self, *, tenant_id, workspace_id, query_embedding, top_k, scope_filter=None) -> list[VectorSearchHit]: ...
    async def delete(self, *, tenant_id, memory_id) -> None: ...

class MemoryServicePort(Protocol):  # mirror for agent_runtime
    async def recall(self, *, tenant_id, workspace_id, query, top_k=10) -> list[MemoryHit]: ...
    async def write(self, *, tenant_id, workspace_id, owner_id, scope, content, metadata=None, expires_at=None) -> MemoryEntry: ...
    async def revoke(self, *, tenant_id, workspace_id, memory_id, actor_id) -> MemoryEntry: ...
```

**关键路由**：

| 路由 | 方法 | 状态码 |
|---|---|---|
| `/v1/memories` | POST / GET | 201 / 200 |
| `/v1/memories/recall` | POST | 200 |
| `/v1/memories/{mid}` | GET / DELETE | 200 / 200 / 404 / 409 |

**事件**：`MemoryWritten` `MemoryRevoked` `MemoryExpiredPurged`。

**agent_runtime 集成**：`RunTurnUseCase` 在 turn 开始处自动调用 `memory_port.recall()`，结果以 bullet 列表渲染进 system prompt；recall 失败不阻断 turn（log warn + fallback 到裸 prompt）。

**Embedding 后端**：`embedding_runtime` 独立 sidecar（`POST /embed` + `GET /healthz`），支持 `noop` / `openai` / `sbert` 三 provider；P4 仅文件骨架，P10 真拆 sidecar。

## 4.4 业务模块（扩展阶段）

### 4.4.1 `model` 模型路由（P6）

**领域对象**：`Model`（tenant-scoped + workspace-可选）`ModelCredential`（AES-GCM 加密）`RoutingPolicy`（priority / round_robin / cost_optim / latency_optim / tenant_default）`QuotaCounter`（tenant + model + window_start 复合主键）。

**关键路由**：
- `POST /v1/model-credentials` 注册加密凭据（admin）
- `GET /v1/model-credentials` 列出凭据
- `POST /v1/model-credentials/{cid}/rotate` 轮换凭据
- `POST /v1/models` 注册模型（绑 credential + routing policy）
- `GET /v1/models` 列表（workspace-scoped：tenant-wide + own-workspace）
- `GET /v1/models/{mid}` / `PATCH` / `DELETE`
- `POST /v1/models/{id}/invoke` 实际 LLM 调用（hot path）
- `POST /v1/routing-policies` / `GET` 列表

**事件**：`ModelRegistered` `ModelInvoked` `ModelQuotaExceeded` `ModelCredentialRotated`。

**安全**：`secrets_ref` 兑现路径 — `ModelCredential.api_key` 永不出现在 JSONB / log / 响应；DB 落 `nonce(12) || ciphertext || tag(16)` AES-GCM envelope；master key 仅 `QZDAP_MODEL_MASTER_KEY` env。

**Quota 原子增量**：`INSERT ... ON CONFLICT (tenant_id, model_id, window_start) DO UPDATE SET input_tokens = input_tokens + EXCLUDED.input_tokens ... RETURNING *` — 单 SQL 原子操作防 overshoot。

**与 agent_runtime 接线**：`LLMPort.stream(req, *, model_id=ModelId | None = None)` — P6 路径走 `ModelService.invoke`；`model_id=None` 走 legacy default（向后兼容 P0–P5）。

### 4.4.2 `channel` 渠道适配（P6）

**领域对象**：`Channel`（feishu / dingtalk / wechatwork / web）+ `ChannelDelivery`（inbound / outbound + pending / sent / delivered / failed 状态机）。

**关键路由**：
- `POST /v1/channels` 注册渠道（自动加密 webhook secret 落 `channel_secrets`）
- `GET /v1/channels` 列表
- `PATCH /v1/channels/{cid}` 启停
- `POST /v1/channels/{cid}/webhook` 接收 inbound（HMAC 签名校验 + 时间戳 skew 防重放）
- `POST /v1/channels/{cid}/send` 出站发送

**事件**：`ChannelMessageReceived` `ChannelReplySent` `ChannelWebhookRejected`。

**Webhook 签名**：`HMAC-SHA256(secret, f"{ts}.{body}")`，`X-Webhook-Timestamp` + `X-Webhook-Signature: sha256=<hex>` headers；±300s skew；`hmac.compare_digest` constant-time。

**渠道适配器**：每个渠道一对 inbound + outbound adapter，解析 / 发送由 `ChannelType` 映射到 adapter 注册表；webhook 路由在 `ChannelService.handle_webhook` 内做 verify → parse → persist delivery → publish `channel.message.received`。

### 4.4.3 `knowledge` 知识包（P7）

**领域对象**：`KnowledgePackage` / `KnowledgeAsset`（原文对象存储） / `KnowledgeChunk`（chunk + embedding）。
**关键路由**：
- `POST /v1/knowledge/packages` 创建包
- `GET /v1/knowledge/packages` 列表
- `GET /v1/knowledge/packages/{pid}` 取详情
- `POST /v1/knowledge/packages/{pid}/revoke` 撤销（级联 vector 删除）
- `POST /v1/knowledge/packages/{pid}/assets/text` 文本摄取（同步 chunk + embed）
- `POST /v1/knowledge/packages/{pid}/assets/{aid}/detach` 撤销资产
- `POST /v1/knowledge/packages/{pid}/search` 检索 top-k（默认 10，最大 50）
**端口**：`KnowledgeRepository` (SQL) / `StoragePort` (`LocalDiskKnowledgeStorage` 默认) / `VectorSearchPort` (`PgVectorStore`，表 `knowledge_chunks_vec`) / `EmbeddingPort` (复用 memory 同一套) / `ChunkerPort` (`FixedWindowChunker`)。
**事件**：`KnowledgePackageCreated` / `KnowledgeAssetUploaded` / `KnowledgeAssetIngested` / `KnowledgePackageRevoked`。
**存储**：原文落 `LocalDiskKnowledgeStorage`，DB 仅存 `storage_uri`（`knowledge-asset://{tenant}/{sha256}`）。向量表 `knowledge_chunks.embedding` (HNSW cosine) + `knowledge_chunks_vec` (qzdap_vector mirror)。
**Secrets**：`secrets_ref` 指向 P5 secrets 表 —— 原始 secrets 永不落 JSONB。

### 4.4.4 `orchestration` 编排（P7）

**领域对象**：`Plan` / `PlanStepDSL`（7 种 kind 的 discriminated union） / `WorkflowRun` / `StepRun`。
**Plan DSL 7 种 kind**：
- `agent`：调 `SubAgentPort.run_turn_to_completion`
- `tool`：调 `ToolDispatchPort.invoke_tool`
- `skill`：调 `SkillDispatchPort.invoke_skill`（队列 + 轮询）
- `subplan`：递归起 `WorkflowRun`
- `parallel`：`asyncio.gather(*branches, return_exceptions=...)`，可设 `fail_fast`
- `conditional`：极简 lexer 表达式（`==` / `!=` / `<` / `>` / `<=` / `>=` / `in` / `contains`），无 `eval()`
- `sequence`：顺序执行（前一步失败即终止）
**模板渲染**：`${variables.x}` + `${steps.<id>.output.<key>}`；`TemplateRendererPort` 注入（v1 = `string.Template` + 自定义 mapping）。
**关键路由**：
- `POST /v1/orchestration/plans` 创建（201）
- `GET /v1/orchestration/plans` 列表
- `GET /v1/orchestration/plans/{id}` 详情
- `POST /v1/orchestration/plans/{id}/runs` 同步起 run（返回终态 + step_runs）
- `GET /v1/orchestration/runs/{id}` 查 run
- `GET /v1/orchestration/runs` 按 plan_id 过滤
- `POST /v1/orchestration/runs/{id}/cancel` 取消
**端口**：`PlanRepository` / `WorkflowRunRepository` / `SubAgentPort`（委托给 agent_runtime `RunTurnCompletionUseCase`）/ `ToolDispatchPort` / `SkillDispatchPort` / `TemplateRendererPort` / `ConditionEvaluatorPort`。
**执行器**：`WorkflowExecutor` 维护 `step_counter` 强制 `max_total_steps`；`asyncio.wait_for` 单步超时；parallel 用 `asyncio.gather`；sequence 前一步失败终止；递归 sub-plan 共享 `step_counter`。
**幂等**：`workflow_runs.idempotency_key` partial unique `(tenant_id, idempotency_key) WHERE NOT NULL` —— 相同 key 第二次创建复用上次 run。
**事件**：`PlanCreated` / `WorkflowRunStarted` / `StepRunCompleted` / `WorkflowRunCompleted` / `WorkflowRunCancelled`。
**Channel 闭环**：`ChannelDispatchSubscriber` 订阅 `ChannelMessageReceived`，起系统 actor（`SYSTEM_USER_ID` / `SYSTEM_AGENT_ID` 确定性 UUID）跑 turn，按 `channel_type` 找 `OutboundAdapter` 回写 reply；LRU dedup（1024 window）防 webhook 重放。

### 4.4.5 `agent_factory` Agent 模板（P8）

**领域对象**：`AgentTemplate` / `AgentVersion`（`draft → published → released → retired`；一旦 `released_at` 非空即不可变）/ `Release`。`AgentVersion` payload 用 typed columns：`system_prompt` / `model_id` / `allowed_tools` / `allowed_skills` / `knowledge_package_ids`（ARRAY）/ `plan_dsl_snapshot`（JSONB 可空）/ `max_total_steps`（1–256，可空）/ `metadata`（JSONB）。

**关键路由**：`/v1/agents`（template CRUD）/ `/v1/agents/{aid}/versions`（version 列表+创建）/ `/v1/agents/{aid}/versions/{vid}`（get）/ `/v1/agents/{aid}/versions/{vid}/notes`（PATCH 仅 draft 可改 `release_notes`）/ `/v1/agents/{aid}/versions/{vid}/publish`（draft → published）/ `/v1/agents/{aid}/versions/{vid}/release`（published → released；先跑 `EvalGate`）/ `/v1/agents/{aid}/versions/{vid}/retire`（released → retired）/ `/v1/agents/{aid}/versions/{vid}/releases`（历史 release）。

**端口**：`AgentTemplateRepository` / `AgentVersionRepository` / `ReleaseRepository` / `EvaluationQueryPort`（由 `evaluation` 模块的 `EvaluationServiceAdapter` 实现）/ `AgentFactoryEventPublisher`。

**门禁触发点**：POST `/release` 入口。`ReleaseAgentVersionUseCase.execute()` 顺序：(1) `policy_guard.check(actor, action="agent.release")`（可选）；(2) 加载 template + version，version 必须在 `published` 状态；(3) `eval_query.latest_passed_run(template_id, version_id)` 查最新已通过 EvalRun，**任一失败 → `BusinessRuleError(code="EVAL_GATE_FAILED", status=422)`**，错误消息分别说明"no passed eval run"/"score < threshold"/"version not published"。

**事件**：`AgentTemplateCreated` / `AgentTemplateArchived` / `AgentVersionDraftCreated` / `AgentVersionPublished` / `AgentReleased` / `AgentRetired`。`released_at` 设置后 ORM 拒绝 UPDATE；use case 校验 `version.is_immutable()` 后禁止调用 `with_*` 方法。

**唯一性**：`agent_templates (tenant_id, name)` UQ + `agent_versions (tenant_id, template_id, version_tag)` UQ。重复创建 → `AgentTemplateNameConflict` / `AgentVersionTagConflict`（HTTP 409）。

### 4.4.6 `evaluation` 评测（P8）

**领域对象**：`EvalDataset`（`kind: builtin|custom`，`status: active|archived`）/ `EvalCase`（ordinal 排序，`expected_keywords` + `min_keywords_hit_ratio` + `max_latency_ms`）/ `EvalRun`（`queued → running → passed|failed|errored` 一次性状态机，frozen dataclass）。`EvalScoreRecord` 不落单独表，订阅 `EvalRunCompleted` 事件入 governance `audit_log.payload.case_scores`（JSONB）。

**关键路由**：`GET /v1/eval/datasets` / `GET /v1/eval/datasets/{did}` / `GET /v1/eval/datasets/{did}/cases` / `POST /v1/eval/runs`（202 立即返回）+ `GET /v1/eval/runs/{rid}` / `GET /v1/eval/runs?template_id=...&version_id=...`。

**端口**：`EvalDatasetRepository` / `EvalRunRepository` / `SubAgentPort`（驱动 agent_runtime `RunTurnCompletionUseCase` 每 case 一个 ephemeral session）/ `AgentFactoryQueryPort`（可选：校验 template+version 存在）/ `EvaluationEventPublisher`。

**Heuristic scorer**（pure function `score_case`）：`matched / max(len(expected), 1) >= min_keywords_hit_ratio` AND `latency_ms <= max_latency_ms` → pass；case-insensitive substring match；任一参数异常 / 超时 → 0 分 + error_message。`EvalRunner` 用 `asyncio.Semaphore(concurrency=settings.evaluation_runner_concurrency)` 限并发；`asyncio.create_task` 起后台任务，`StartEvalRunUseCase` 立即返回 queued run。

**门禁**：release endpoint 经 `EvaluationQueryPort.latest_passed_run()` 拉最新 `passed` 行，要求 `status == passed AND mean_score >= settings.agent_factory_eval_score_min AND completed_at IS NOT NULL`。50 case `golden-default` dataset 由 lifespan 启动时按 tenant seed（幂等），保证任何 tenant 第一次 GET `/v1/eval/datasets` 就有 builtin 评测集。

**唯一性**：`eval_datasets (tenant_id, name)` UQ；`eval_runs (tenant_id, idempotency_key)` partial UQ `WHERE NOT NULL` —— 重复 POST `/runs` 同 key 返回上次 `run_id`（与 P7 `workflow_runs` 同 pattern）。

**事件**：`EvalRunStarted` / `EvalRunCompleted`（payload 含 50 条 case_score 详情）/ `EvalRunFailed`。

### 4.4.7 `observability_module` 业务级埋点（P9）

**领域对象**：

| 对象 | 字段 | 说明 |
|---|---|---|
| `RunRecord` | `id, tenant_id, workspace_id, run_type, source_id, actor_id, completed_at, latency_ms, status, metadata, created_at` | 单次业务运行的元数据 |
| `CostRecord` | `id, tenant_id, workspace_id, run_id, cost_type, amount_usd (NUMERIC 12,6), quantity, unit, currency, model_id, metadata, created_at` | 单次业务的成本（与 RunRecord 1:N） |

`RunType`：`llm | tool | skill | memory | knowledge | workflow | channel | eval | governance`。
`RunStatus`：`succeeded | failed | running`。`CostType`：`llm_input | llm_output | tool | skill | memory | knowledge | channel`。

**PricingCatalog**（`application/pricing.py`，pure）：

**数据库**（`migrations/versions/0013_observability.py`）：

|---|---|---|

**默认 seed**（`fixtures/default_plans.py` + lifespan `_seed_default_plans`）：

```python
DEFAULT_PLANS = [
    PlanSpec(code="free", price=0, limits={"max_turns_per_month": 1000}, features=("basic_tools",)),
    PlanSpec(code="pro", price=49, limits={"max_turns_per_month": 50000}, features=("basic_tools","advanced_memory")),
```

**`assign_subscription` 状态机**：

```
active     ──switch_plan──>   active     (更新 plan_id, plan_code, started_at)
active     ──suspend───>      suspended  (admin only)
suspended  ──reactivate─>     active
*          ──cancel───>       cancelled  (ends_at = now)
```

`retired` plan 不可分配（BusinessRuleError → 422 `PLAN_RETIRED`）。

## 4.5 起步阶段模块优先级（P0-P4）

| 阶段 | 模块 | 关键交付 |
|---|---|---|
| **P0 准备** | libs 全部 + `identity` | workspace / 守则 / 多租户 |
| **P1 agent_runtime** | agent_runtime | Session / Turn / SSE 流式 |
| **P2 tool** | tool | tool 注册 / MCP 适配 / 调用 |
| **P3 skill** | skill | skill 包 / 沙箱 / RunToken |
| **P4 memory** | memory | 向量存储 / 写入 / 检索 / 撤销 |

**P4 结束时闭环**：

```
User → agent_runtime (Session/Turn/SSE) → tool / skill / memory → Response
                                                            ↓
                                            governance（policy gate）
                                                            ↓
                                            observability_module（埋点）
```

P5 起逐步补齐治理与扩展模块（详见 [12-实施计划.md](12-实施计划.md)）。

| 维度 | 原模板（8 模块） | Enterprise-Agent-OS（14 模块） |
