# 08 · 持久化与迁移

> ORM 封装、UnitOfWork、Alembic 迁移、硬删语义、多租户隔离、持久化策略。

> **基于 docs/python-refactor/08-持久化与迁移.md 模板**。
> 与原模板差异：所有表强制带 `tenant_id` 列；ORM 自动注入租户过滤；Event 表分区按租户；skill / tool / knowledge 产物走对象存储。

---

## 8.1 总体策略

| 项 | 选择 |
|---|---|
| ORM | **SQLAlchemy 2.0 async**（asyncpg 驱动） |
| 迁移工具 | **Alembic**（统一脚本） |
| 会话管理 | **UnitOfWork** + `SessionFactory` |
| ORM 模型归属 | `modules/<m>/adapter/persistence/models.py`（不外露） |
| 跨模块 ID 类型 | `libs/schema` Pydantic |
| 多租户 | 所有表带 `tenant_id`；ORM 自动注入过滤 |
| 软删 | 仅 `memory_entries.revoked`；其他表硬删 |
| 硬删语义 | `QZDAP_ENV != demo` 时，删除走 `PersistDelete(Sync)` |
| 向量存储 | pgvector（默认；同库） |
| 对象存储 | S3 兼容（MinIO dev / 阿里云 OSS 生产） |

## 8.2 SQLAlchemy 基础

### 8.2.1 Base

```python
# libs/persistence/src/qzdap_persistence/base.py
from sqlalchemy.orm import DeclarativeBase, Mapped, mapped_column
from sqlalchemy import String


class Base(DeclarativeBase):
    pass


class TenantScopedMixin:
    """约定：所有租户相关表必须 include"""

    tenant_id: Mapped[str] = mapped_column(String, index=True, nullable=False)
```

### 8.2.2 SessionFactory

```python
# libs/persistence/src/qzdap_persistence/session_factory.py
from sqlalchemy.ext.asyncio import create_async_engine, async_sessionmaker


class SessionFactory:
    def __init__(self, url: str, *, pool_size=20, max_overflow=10, echo=False):
        self.engine = create_async_engine(
            url, pool_size=pool_size, max_overflow=max_overflow, echo=echo
        )
        self.sessionmaker = async_sessionmaker(self.engine, expire_on_commit=False)

    def session(self):
        return self.sessionmaker()

    async def close(self):
        await self.engine.dispose()
```

### 8.2.3 UnitOfWork

```python
# libs/persistence/src/qzdap_persistence/unit_of_work.py
class UnitOfWork:
    def __init__(self, factory: SessionFactory):
        self._factory = factory
        self.session = None

    async def __aenter__(self):
        self.session = self._factory.session()
        return self

    async def __aexit__(self, exc_type, exc, tb):
        try:
            if exc_type is None:
                await self.session.commit()
            else:
                await self.session.rollback()
        finally:
            await self.session.close()
```

## 8.3 多租户 ORM 守卫

### 8.3.1 自动注入 tenant_id 过滤

```python
# libs/persistence/src/qzdap_persistence/tenant_query.py
from sqlalchemy import event
from qzdap_kernel import current_tenant, current_workspace
from .base import TenantScopedMixin


@event.listens_for(Session, "do_orm_execute")
def _enforce_tenant(state):
    if not state.is_select:
        return
    tenant = current_tenant()
    if tenant is None:
        # 后台任务 / migration 场景可显式 bypass
        return
    for desc in state.statement.column_descriptions:
        entity = desc.get("entity")
        if entity and hasattr(entity, "tenant_id"):
            state.statement = state.statement.where(entity.tenant_id == tenant.tenant_id)
```

### 8.3.2 约定

- 所有租户相关 ORM 类必须 include `TenantScopedMixin`
- 没有 `tenant_id` 列的查询不强制注入（系统表、审计表）
- Lint 规则：CI 检查 `modules/*/adapter/persistence/models.py` 强制 import `TenantScopedMixin`

### 8.3.3 workspace 过滤

`workspace_id` 不是所有表都强制（部分表跨 workspace 共享），按需在仓储层显式 `where(workspace_id == current_workspace().id)`。

## 8.4 ORM 模型（agent_runtime 示例）

```python
# modules/agent_runtime/src/qzdap/modules/agent_runtime/adapter/persistence/models.py
from sqlalchemy import String, DateTime, ForeignKey, JSON, Index
from sqlalchemy.orm import Mapped, mapped_column, relationship
from qzdap_persistence.base import Base, TenantScopedMixin


class SessionOrm(Base, TenantScopedMixin):
    __tablename__ = "sessions"
    __table_args__ = (
        Index("ix_sessions_tenant_workspace_status", "tenant_id", "workspace_id", "status"),
        Index("ix_sessions_tenant_owner_created", "tenant_id", "owner_id", "created_at"),
    )

    id: Mapped[str] = mapped_column(String, primary_key=True)
    workspace_id: Mapped[str] = mapped_column(String, index=True)
    owner_id: Mapped[str] = mapped_column(String, index=True)
    agent_id: Mapped[str] = mapped_column(String, index=True)
    agent_version: Mapped[str] = mapped_column(String)
    status: Mapped[str] = mapped_column(String, default="open")
    created_at: Mapped[datetime] = mapped_column(DateTime(timezone=True))
    closed_at: Mapped[datetime | None] = mapped_column(DateTime(timezone=True), nullable=True)
    metadata_: Mapped[dict] = mapped_column("metadata", JSON, default=dict)

    turns: Mapped[list["TurnOrm"]] = relationship(
        back_populates="session", cascade="all, delete-orphan"
    )


class TurnOrm(Base, TenantScopedMixin):
    __tablename__ = "turns"
    __table_args__ = (
        Index("ix_turns_tenant_session_started", "tenant_id", "session_id", "started_at"),
    )

    id: Mapped[str] = mapped_column(String, primary_key=True)
    workspace_id: Mapped[str] = mapped_column(String, index=True)
    session_id: Mapped[str] = mapped_column(String, ForeignKey("sessions.id"), index=True)
    user_input: Mapped[str] = mapped_column(String)
    status: Mapped[str] = mapped_column(String, default="running")
    started_at: Mapped[datetime] = mapped_column(DateTime(timezone=True))
    finished_at: Mapped[datetime | None] = mapped_column(DateTime(timezone=True))
    final_response: Mapped[str | None] = mapped_column(String, nullable=True)
    usage: Mapped[dict] = mapped_column(JSON, default=dict)
```

## 8.5 仓储示例

```python
# modules/agent_runtime/src/qzdap/modules/agent_runtime/adapter/persistence/session_repo.py
from sqlalchemy import select, delete
from libs.persistence import SessionFactory


class PgSessionRepo:
    def __init__(self, factory: SessionFactory):
        self._factory = factory

    async def add(self, session: Session) -> None:
        async with self._factory.session() as s:
            s.add(SessionOrm.from_entity(session))
            await s.commit()

    async def get(self, id: SessionId) -> Session | None:
        async with self._factory.session() as s:
            orm = (
                await s.execute(select(SessionOrm).where(SessionOrm.id == str(id)))
            ).scalar_one_or_none()
            return orm.to_entity() if orm else None

    async def delete(self, id: SessionId) -> None:
        """硬删：先删 turns，再删 sessions"""
        async with self._factory.session() as s:
            await s.execute(delete(TurnOrm).where(TurnOrm.session_id == str(id)))
            await s.execute(delete(SessionOrm).where(SessionOrm.id == str(id)))
            await s.commit()
```

## 8.7 硬删语义

### 8.7.1 模式

| 环境 | 行为 |
|---|---|
| `QZDAP_ENV=demo` | 内存 store；不 Persist |
| `QZDAP_ENV=development` 及以上 | PG hydrate；Upsert 写回；硬删必须 `PersistDelete(Sync)` |

| 模块 | 主表 | 子表 |
|---|---|---|
| agent_runtime | `sessions` | `turns` `tool_calls` `skill_invocations` |
| tool | `tools` | `tool_calls` |
| skill | `skill_packages` | `skill_installs` `skill_invocations` |
| memory | `memory_entries` | （软删 `revoked`，不级联） |
| knowledge | `knowledge_packages` | `knowledge_assets` |

| channel | `channels` | `channel_deliveries` |

## 8.8 事务边界与发布顺序

### 8.8.1 反模式

```python
# 错误：在事务内发布事件
async def create_session(self, ctx, command):
    async with self.uow_factory() as uow:
        await self.sessions.add(session)
        await self.events.publish(SessionStarted(...))  # ❌
        await uow.commit()
```

### 8.8.2 正例

```python
# 正确：先提交事务，再发布事件
async def create_session(self, ctx, command):
    session = Session.create(...)
    async with self.uow_factory() as uow:
        await self.sessions.add(session)
        await uow.commit()
    # 事务外发布
    await self.events.publish(SessionStarted(...))
    return session
```

## 8.9 多副本与读写分离

```python
class SessionFactory:
    def __init__(self, url, *, replica_url=None, replica_mode="active"):
        self.engine = create_async_engine(url, ...)
        self.replica_engine = (
            create_async_engine(replica_url, ...)
            if replica_url and replica_mode == "standby"
            else None
        )

    def session(self, *, read_only=False):
        if read_only and self.replica_engine:
            return async_sessionmaker(self.replica_engine)()
        return self.sessionmaker()
```

## 8.14 与原模板的关键差异

| 维度 | 原模板 | Enterprise-Agent-OS |
|---|---|---|
| 多租户 | 仅 Workspace | **Tenant + Workspace** 强制两级 |
| ORM 守卫 | 无 | 自动注入 `tenant_id` 过滤 |
| ORM 约定 | 无 | 必须 include `TenantScopedMixin` |
| 向量 | 不在主库 | pgvector 同库起步 |
| 硬删覆盖表 | 5 张 | 13 张（含 platform / evaluation） |
| 租户表 | 不可删 | `tenants` 不可硬删（仅 410） |
