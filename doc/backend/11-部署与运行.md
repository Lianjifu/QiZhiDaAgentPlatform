## 11.1 Makefile 入口

```makefile
# qizhida-agent-platform/Makefile

.PHONY: install build run-app run-app-with-gateway run-skill-runtime \
        run-tool-runtime run-embedding-runtime run-rag \
        test test-contract smoke db-upgrade db-downgrade db-revision \
        lint import-lint type-check clean

install:
	uv sync

build:
	docker compose -f deploy/compose.yml build

# ---------- 运行 ----------

run-app:
	uv run uvicorn qzdap.composition.main:create_app \
		--host 0.0.0.0 --port 8100 --workers 4 --loop uvloop \
		--access-log --no-server-header

run-app-with-gateway:
	@echo "Starting qzdap-app on :8100 and qzdap-gateway on :8089"
	uv run uvicorn qzdap.composition.main:create_app --host 0.0.0.0 --port 8100 --workers 4 --loop uvloop &
	uv run uvicorn qzdap.gateway.main:create_gateway --host 0.0.0.0 --port 8089 --loop uvloop

run-skill-runtime:
	uv run uvicorn qzdap.runtimes.skill_runtime.app.main:app \
		--host 0.0.0.0 --port 8093 --workers 2 --loop uvloop

run-tool-runtime:
	uv run uvicorn qzdap.runtimes.tool_runtime.app.main:app \
		--host 0.0.0.0 --port 8094 --workers 2 --loop uvloop

run-embedding-runtime:
	uv run uvicorn qzdap.runtimes.embedding_runtime.app.main:app \
		--host 0.0.0.0 --port 8095 --loop uvloop

# ---------- 数据库 ----------

db-upgrade:
	uv run alembic upgrade head

db-downgrade:
	uv run alembic downgrade -1

db-revision:
	uv run alembic revision --autogenerate -m "$(name)"

db-reset-dev:
	uv run alembic downgrade base
	uv run alembic upgrade head

# ---------- 测试 ----------

test:
	uv run pytest -q --cov

test-contract:
	uv run pytest tests/contract -q

smoke:
	uv run python tests/e2e/smoke.py --base http://127.0.0.1:8100

# ---------- 守则 ----------

lint:
	uv run ruff check .
	uv run ruff format --check .

import-lint:
	uv run lint-imports --config .importlinter.ini

type-check:
	uv run mypy libs modules composition gateways runtimes

# ---------- 清理 ----------

clean:
	find . -type d -name __pycache__ -exec rm -rf {} +
	find . -type d -name .pytest_cache -exec rm -rf {} +
	find . -type d -name .mypy_cache -exec rm -rf {} +
	find . -type d -name .ruff_cache -exec rm -rf {} +
```

## 11.2 docker-compose

### 11.2.1 `deploy/compose.yml`

```yaml
version: "3.9"

services:
  postgres:
    image: postgres:16
    restart: unless-stopped
    environment:
      POSTGRES_USER: postgres
      POSTGRES_PASSWORD: postgres
      POSTGRES_DB: qzdap
    ports: ["5432:5432"]
    volumes:
      - qzdap_postgres:/var/lib/postgresql/data
    healthcheck:
      test: ["CMD-SHELL", "pg_isready -U postgres"]
      interval: 10s
      timeout: 5s
      retries: 5

  redis:
    image: redis:7
    restart: unless-stopped
    ports: ["6379:6379"]
    healthcheck:
      test: ["CMD", "redis-cli", "ping"]
      interval: 10s
      timeout: 5s
      retries: 5

  minio:
    image: minio/minio:latest
    restart: unless-stopped
    command: server /data --console-address ":9001"
    environment:
      MINIO_ROOT_USER: minio
      MINIO_ROOT_PASSWORD: minio123
    ports:
      - "9000:9000"   # API
      - "9001:9001"   # Console
    volumes:
      - qzdap_minio:/data
    healthcheck:
      test: ["CMD", "curl", "-fsS", "http://localhost:9000/minio/health/live"]
      interval: 10s
      timeout: 5s
      retries: 5

  app:
    build:
      context: ..
      dockerfile: deploy/Dockerfile
    command:
      - uvicorn
      - qzdap.composition.main:create_app
      - --host=0.0.0.0
      - --port=8100
      - --workers=4
      - --loop=uvloop
    env_file: [.env]
    environment:
      QZDAP_DATABASE_URL: postgresql+asyncpg://postgres:postgres@postgres:5432/qzdap
      QZDAP_REDIS_URL: redis://redis:6379/0
      QZDAP_OBJECT_STORAGE_URL: http://minio:9000
      QZDAP_OBJECT_STORAGE_BUCKET: qzdap-artifacts
      QZDAP_SKILL_RUNTIME_URL: http://skill-runtime:8093
      QZDAP_TOOL_RUNTIME_URL: http://tool-runtime:8094
      QZDAP_EMBEDDING_RUNTIME_URL: http://embedding-runtime:8095
      QZDAP_RUNTIME_MODE: remote
    depends_on:
      postgres: { condition: service_healthy }
      redis: { condition: service_healthy }
      minio: { condition: service_healthy }
      skill-runtime: { condition: service_started }
      tool-runtime: { condition: service_started }
      embedding-runtime: { condition: service_started }
    ports: ["8100:8100"]
    healthcheck:
      test: ["CMD", "curl", "-fsS", "http://localhost:8100/healthz"]
      interval: 15s
      timeout: 5s
      retries: 5

  gateway:
    build:
      context: ..
      dockerfile: deploy/Dockerfile
    command:
      - uvicorn
      - qzdap.gateway.main:create_gateway
      - --host=0.0.0.0
      - --port=8089
      - --loop=uvloop
    environment:
      QZDAP_APP_UPSTREAM: http://app:8100
      QZDAP_REDIS_URL: redis://redis:6379/0
    depends_on:
      app: { condition: service_healthy }
    ports: ["8089:8089"]
    profiles: ["with-gateway"]

  skill-runtime:
    build:
      context: ..
      dockerfile: runtimes/dqzdap_skill_runtime/Dockerfile
    command: uvicorn qzdap.runtimes.skill_runtime.app.main:app --host 0.0.0.0 --port 8093 --workers 2
    ports: ["8093:8093"]
    volumes:
      - /var/run/docker.sock:/var/run/docker.sock    # 沙箱内启动 docker
    profiles: ["with-runtimes"]

  tool-runtime:
    build:
      context: ..
      dockerfile: runtimes/dqzdap_tool_runtime/Dockerfile
    command: uvicorn qzdap.runtimes.tool_runtime.app.main:app --host 0.0.0.0 --port 8094 --workers 2
    ports: ["8094:8094"]
    profiles: ["with-runtimes"]

  embedding-runtime:
    build:
      context: ..
      dockerfile: runtimes/dqzdap_embedding_runtime/Dockerfile
    command: uvicorn qzdap.runtimes.embedding_runtime.app.main:app --host 0.0.0.0 --port 8095
    ports: ["8095:8095"]
    profiles: ["with-runtimes"]

volumes:
  qzdap_postgres:
  qzdap_minio:
```

### 11.2.2 启动

```bash

# 基础（含 runtimes）

# 含网关
```

## 11.4 Dockerfile

### 11.4.1 业务 Dockerfile

```dockerfile
# deploy/Dockerfile
FROM python:3.12-slim AS base

ENV PYTHONUNBUFFERED=1 \
    PYTHONDONTWRITEBYTECODE=1 \
    PIP_NO_CACHE_DIR=1

RUN apt-get update && apt-get install -y --no-install-recommends \
    gcc libpq-dev curl \
    && rm -rf /var/lib/apt/lists/*

RUN pip install uv

WORKDIR /app

# 先复制依赖文件以利用缓存
COPY pyproject.toml uv.lock ./
COPY libs/ ./libs/
COPY modules/ ./modules/
COPY composition/ ./composition/
COPY gateways/ ./gateways/
COPY migrations/ ./migrations/
COPY runtimes/ ./runtimes/

RUN uv sync --no-dev --frozen

EXPOSE 8100

HEALTHCHECK --interval=15s --timeout=5s --retries=5 \
    CMD curl -fsS http://localhost:8100/livez || exit 1

CMD ["uvicorn", "qzdap.composition.main:create_app", \
     "--host=0.0.0.0", "--port=8100", "--workers=4", "--loop=uvloop"]
```

## 11.6 性能目标

| 指标 | 目标 | 备注 |
|---|---|---|
| 冷启动时间 | ≤ 30s | 含 ensure |
| 启动后内存 | ≤ 800 MB / worker | 4 workers × 800 MB = 3.2 GB |
| P95 单回合延迟 | ≤ 1500ms | SSE 主路径 |
| HTTP 普通接口 P95 | ≤ 200ms | |
| SSE 流式 P95（首个 chunk） | ≤ 1000ms | |
| Tool 调用 P95 | ≤ 500ms | 同步 |
| Skill 执行 P95 | ≤ 30s | 含沙箱启动 |
| Memory 检索 P95 | ≤ 200ms | top-k=10 |
| `/healthz` P95 | ≤ 10ms | |
| `/metrics` P95 | ≤ 50ms | |
| 事件总线投递 P95 | ≤ 100ms | 进程内 |

### 11.6.1 uvicorn 配置

- `workers = (2 * CPU) + 1`
- `--loop uvloop`
- `--http httptools`
- `--no-server-header`

### 11.7.2 切到 RedisStreamBus

```python
# composition/qzdap_app/container.py
from libs.messaging import RedisStreamBus

c.register_singleton(
    EventBus,
    RedisStreamBus(
        redis=c.resolve(Redis),
        stream_key_template="qzdap:events:{tenant_id}",  # 按租户分片
        consumer_group="qzdap-app",
        consumer_name=settings.instance_id,
    ),
)
```

> 多副本时 `InProcessBus` 不够用，必须切 `RedisStreamBus`。
> 按租户分片避免跨租户干扰。

## 11.10 安全清单

- [ ] `QZDAP_BAN_MOCK_TOKEN=1` 在所有非 demo 环境
- [ ] `QZDAP_JWT_SECRET` 从 secret manager 注入
- [ ] 所有 DB / Redis / 对象存储凭据从 secret manager
- [ ] HTTPS 由网关 / 反向代理终结
- [ ] API Key 在 header，不在 URL
- [ ] mTLS 仅在 staging / production（远期 SPIRE）
- [ ] 敏感字段（邮箱 / token / API Key / 凭据）在日志脱敏
- [ ] 附件 / 产物下载走签名 URL（5 分钟过期）
- [ ] 限流开启（`RateLimitMiddleware`）
- [ ] 多租户头必填（中间件强制）

## 11.11 故障排查速查

| 现象 | 检查 |
|---|---|
| `/healthz` 503 | PG / Redis / Vector 可达性 |
| `IDENTITY_MOCK_FORBIDDEN` | `QZDAP_BAN_MOCK_TOKEN=1` 且用了 `mock-*-token` |
| `TENANT_DENIED` / `WORKSPACE_DENIED` | JWT / API Key 中 tenant 与 header 不一致 |
| SSE 流式不增量 | 网关是否缓冲；显式 `X-Accel-Buffering: no` |
| 事件未触发订阅者 | EventBus 是否 `start()`；订阅是否在 `lifespan` 注册 |
| 跨租户查询被阻止 | ORM 守卫生效；租户上下文是否设置 |
| Alembic 报 "no such table" | `make db-upgrade`；CI 上 `migrations/env.py` 是否 import 了所有 ORM |
| 沙箱执行超时 | `QZDAP_SKILL_RUNTIME_URL` 是否可达；网络策略 |
| Tool 调 MCP 失败 | `QZDAP_TOOL_RUNTIME_URL` 可达；MCP server 端点正确 |
| 启动后内存暴涨 | uvicorn workers 是否过多；PG 池是否泄漏 |

## 11.14 与原模板的关键差异

| 维度 | 原模板 | Enterprise-Agent-OS |
|---|---|---|
| 环境变量前缀 | `DE_` | `QZDAP_` |
| 对象存储 | 无 | MinIO（dev）+ OSS（生产） |
| 远程 Runtime | 2 个 | **3 个**（skill / tool / embedding） |
| Embedding Runtime | 无 | 独立服务，统一管理 API Key |
| Tool Runtime | 无 | 独立（统一 MCP / OpenAPI 适配） |
| 多租户故障排查 | 无 | TENANT_DENIED / 跨租户查询阻止 |
