# 06 · 接口规范

> RESTful 严格状态码、错误码映射、API Key / MCP / Tool 调用协议、SSE 流式规范。

> **基于 docs/python-refactor/06-接口规范.md 模板**。
> 与原模板差异：新增 API Key 鉴权、MCP 协议适配、Tool 调用协议、多租户头（X-Tenant-Id）。

---

## 6.1 接口设计原则

| 原则 | 说明 |
|---|---|
| **RESTful 严格状态码** | 不只是 200；201/202/204/207/4xx/5xx 严格区分 |
| **资源命名** | 复数名词、`/v1/` 前缀、kebab-case |
| **Location header** | 创建返回 201 + `Location` |
| **错误统一 envelope** | `{"error": {"code", "message", "details"}}` |
| **SSE 主路径** | 流式响应显式 `X-Accel-Buffering: no` |
| **多租户头** | `X-Tenant-Id` + `X-Workspace-Id` 必填 |
| **可缓存** | GET 响应带 ETag；支持 `If-None-Match` |

---

## 6.2 请求头规范

| 头 | 必填 | 说明 |
|---|---|---|
| `Authorization` | 二选一 | `Bearer <jwt>` |
| `X-Api-Key` | 二选一 | API Key（M2M） |
| `X-Tenant-Id` | 必填 | 平台租户 ID |
| `X-Workspace-Id` | 必填 | 工作区 ID |
| `X-Trace-Id` | 否 | 上游 trace 标识（可由网关注入） |
| `X-Request-Id` | 否 | 请求幂等键 |
| `If-Match` | 条件 | ETag / version，用于乐观锁 |
| `Content-Type` | POST/PATCH 必填 | `application/json` |
| `Accept` | 否 | `application/json` 或 `text/event-stream` |

## 6.3 状态码使用规范

### 6.3.1 成功码

| 状态码 | 场景 | 必备响应 |
|---|---|---|
| **200 OK** | 同步查询 / 更新 | body 含 `data` |
| **201 Created** | 资源创建 | `Location` header 指向资源 URL |
| **202 Accepted** | 异步任务 / 待审批 | body 含 `task_id` / `approval_id`；可附 SSE 链接 |
| **204 No Content** | 删除 / 关闭成功 | 无 body |
| **207 Multi-Status** | 批量部分成功 | body 含 `results: [{status, ...}]` |

### 6.3.2 客户端错误码

| 状态码 | 触发 | error.code |
|---|---|---|
| **400 Bad Request** | schema 校验失败 | `BAD_REQUEST` |
| **401 Unauthorized** | 无 token / 过期 | `UNAUTHORIZED` |
| **401** | mock-*-token 被禁 | `IDENTITY_MOCK_FORBIDDEN` |
| **403 Forbidden** | 角色不足 | `FORBIDDEN` |
| **403** | policy deny | `ACTION_DENIED` |
| **403** | 跨 workspace | `WORKSPACE_DENIED` |
| **403** | 跨 tenant | `TENANT_DENIED` |
| **404 Not Found** | 资源不存在 | `NOT_FOUND` |
| **409 Conflict** | 状态冲突 / 唯一约束 | `CONFLICT` |
| **410 Gone** | 资源已硬删 | `GONE` |
| **412 Precondition Failed** | `If-Match` 失败 | `PRECONDITION_FAILED` |
| **422 Unprocessable** | 语义校验失败 | `UNPROCESSABLE` |
| **422** | 评测门禁未通过 | `EVAL_GATE_FAILED` |
| **429 Too Many Requests** | 限流 / 配额耗尽 | `RATE_LIMITED` / `QUOTA_EXCEEDED` |

429 必带 `Retry-After` header。

### 6.3.3 服务端错误码

| 状态码 | 触发 | error.code |
|---|---|---|
| **500 Internal Server Error** | 未捕获异常 | `INTERNAL_ERROR` |
| **502 Bad Gateway** | 上游 5xx（LLM / Tool / Skill） | `UPSTREAM_UNAVAILABLE` |
| **503 Service Unavailable** | 依赖不可用 | `DEPENDENCY_DOWN` |
| **504 Gateway Timeout** | 沙箱 / Tool 超时 | `SANDBOX_TIMEOUT` / `UPSTREAM_TIMEOUT` |
| **507 Insufficient Storage** | 存储配额 | `STORAGE_QUOTA_EXCEEDED` |

## 6.4 错误响应 envelope

```json
{
  "error": {
    "code": "ACTION_DENIED",
    "message": "Action is denied by policy rule pol-xxx",
    "details": {
      "policy_id": "pol-xxx",
      "rule": "max_amount > 10000",
      "trace_id": "abc123"
    }
  }
}
```

- `code`：机器可读，固定枚举值
- `message`：人类可读，i18n 通过 `Accept-Language`
- `details`：可选，携带上下文（policy_id、trace_id 等）
- `trace_id`：服务端自动注入，便于排查

---

## 6.5 多租户头（X-Tenant-Id / X-Workspace-Id）

### 6.5.1 校验规则

- `X-Tenant-Id` 必须与 JWT / API Key 中绑定的 tenant 一致；不一致返回 `403 TENANT_DENIED`
- `X-Workspace-Id` 必须 ∈ `Principal.workspace_ids`；不在返回 `403 WORKSPACE_DENIED`

### 6.5.2 内部传递

所有 ORM 查询 / 缓存 key / 事件 stream 都自动注入 `tenant_id`（约定 ORM 模型有 `tenant_id` 列）。

### 6.5.3 管理后台

`/v1/identity/*` 与 `/v1/platform/*` 走 `X-Admin-Token` 头，独立鉴权；不要求 `X-Tenant-Id`。

## 6.6 鉴权双轨

### 6.6.1 JWT（用户态）

```
Authorization: Bearer <jwt>
```

JWT payload：

```json
{
  "sub": "user_xxx",
  "tenant_id": "tnt_xxx",
  "workspace_ids": ["ws_aaa", "ws_bbb"],
  "roles": ["user", "admin"],
  "exp": 1735689600,
  "iat": 1735603200
}
```

### 6.6.2 API Key（M2M）

```
X-Api-Key: qzdap_pk_<tenant>_<random>
```

- 形式：`qzdap_pk_<tenant_id_short>_<32字符随机>`
- 存哈希（argon2）
- 绑定 tenant；不可跨租户
- 默认 1000 req/min
- 支持 `X-Api-Key-Scope: tool:invoke,agent:run` 限定范围

### 6.6.3 拒绝 mock token

```
QZDAP_BAN_MOCK_TOKEN=1（默认）
QZDAP_ALLOW_DEMO_TOKEN=0（默认）
```

`mock-*-token` 在非 demo 环境 → 401 `IDENTITY_MOCK_FORBIDDEN`。

## 6.7 响应 envelope

### 6.7.1 成功响应

```json
{
  "data": { ... },
  "meta": {
    "trace_id": "abc123",
    "request_id": "req_xxx"
  }
}
```

### 6.7.2 分页

```json
{
  "data": [ ... ],
  "meta": {
    "page": 1,
    "page_size": 20,
    "total": 142,
    "next_cursor": "cur_xxx"
  }
}
```

支持 `?cursor=...` 游标分页（深分页场景）。

## 6.8 SSE 流式规范

### 6.8.1 响应头

```
Content-Type: text/event-stream
Cache-Control: no-cache
X-Accel-Buffering: no
Connection: keep-alive
```

### 6.8.2 事件格式

```
event: start
data: {"turn_id": "trn_xxx", "trace_id": "abc"}

event: chunk
data: {"content": "你好"}

event: tool_call
data: {"id": "tcc_xxx", "tool_name": "search_web", "arguments": {...}}

event: tool_result
data: {"id": "tcc_xxx", "result": {...}}

event: done
data: {"turn_id": "trn_xxx", "status": "succeeded", "usage": {"input": 123, "output": 456}}

```

### 6.8.3 错误事件

```
event: error
data: {"code": "ACTION_DENIED", "message": "..."}

event: timeout
data: {"message": "stream timeout after 30s"}
```

### 6.8.4 心跳

每 15 秒一个 `:heartbeat` 注释行，防止代理超时。

## 6.9 MCP 协议适配（Tool 模块）

### 6.9.1 概述

Tool 模块作为 MCP server 注册到平台，外部 MCP client 也可被反向注册为 Tool。

### 6.9.2 平台作为 MCP Server

暴露端点：`POST /mcp` （JSON-RPC 2.0）。

```json
// initialize
{ "jsonrpc": "2.0", "id": 1, "method": "initialize", "params": {
    "protocolVersion": "2024-11-05",
    "capabilities": {},
    "clientInfo": {"name": "test-client", "version": "1.0"}
}}

// tools/list
{ "jsonrpc": "2.0", "id": 2, "method": "tools/list" }

// tools/call
{ "jsonrpc": "2.0", "id": 3, "method": "tools/call", "params": {
    "name": "search_web",
    "arguments": {"query": "今天天气"}
}}
```

### 6.9.3 平台作为 MCP Client

Tool 模块支持反向注册外部 MCP server：

```python
# modules/tool/src/qzdap/modules/tool/adapter/external/mcp_client.py
class MCPClientAdapter:
    """调外部 MCP server 上的工具"""

    async def invoke(self, server_url: str, method: str, params: dict) -> dict:
        async with self._client.stream(
            "POST",
            server_url,
            json={
                "jsonrpc": "2.0",
                "id": uuid4().hex,
                "method": method,
                "params": params,
            },
        ) as r:
            async for line in r.aiter_lines():
                yield json.loads(line)
```

## 6.10 Tool 调用协议

### 6.10.1 三种协议

| 协议 | 适用 | 端点形态 |
|---|---|---|
| **MCP** | 通用 MCP 兼容 | `POST /mcp` |
| **OpenAPI** | 既有 OpenAPI 服务 | 直接转发 HTTP |
| **custom** | 自定义 JSON-RPC | 平台适配器 |

### 6.10.2 注册 Tool（OpenAPI 示例）

```http
POST /v1/tools
Authorization: Bearer <jwt>
X-Tenant-Id: tnt_xxx
X-Workspace-Id: ws_xxx
Content-Type: application/json

{
  "name": "fetch_github_issue",
  "protocol": "openapi",
  "version": "1.0.0",
  "spec": {
    "openapi": "3.0.0",
    "servers": [{"url": "https://api.github.com"}],
    "paths": {
      "/repos/{owner}/{repo}/issues/{id}": {
        "get": {
          "operationId": "get_issue",
          "parameters": [...]
        }
      }
    }
  },
  "auth_config": {
    "type": "bearer",
    "credential_ref": "cred_xxx"
  }
}
```

### 6.10.3 调用 Tool

```http
POST /v1/tools/fetch_github_issue/invoke
Content-Type: application/json

{
  "operation": "get_issue",
  "arguments": {
    "owner": "anthropics",
    "repo": "claude-code",
    "id": 123
  }
}
```

成功响应：

```json
{
  "data": {
    "result": { "title": "...", "body": "..." },
    "latency_ms": 234,
    "trace_id": "abc"
  }
}
```

错误：

```json
{
  "error": {
    "code": "UPSTREAM_UNAVAILABLE",
    "message": "GitHub API returned 503",
    "details": { "upstream_status": 503 }
  }
}
```

### 6.10.4 批量调用

```http
POST /v1/tools/batch_invoke
```

响应 207 Multi-Status：

```json
{
  "results": [
    {"name": "tool_a", "status": 200, "result": {...}},
    {"name": "tool_b", "status": 502, "error": {"code": "UPSTREAM_UNAVAILABLE"}}
  ]
}
```

## 6.11 Skill 调用协议

### 6.11.1 RunToken

```python
# skill 模块签发
run_token = jwt.encode(
    {
        "skill_id": "skl_xxx",
        "tenant_id": "tnt_xxx",
        "exp": now + 300,  # 5 分钟
        "iat": now,
    },
    settings.skill_run_secret,
    algorithm="HS256",
)
```

### 6.11.2 调用

```http
POST /v1/skills/parse_docx/invoke
Content-Type: application/json
X-Run-Token: <run_token>

{
  "inputs": {
    "file_id": "fil_xxx",
    "extract_tables": true
  }
}
```

成功：200 + `data.result`
超时：504 `SANDBOX_TIMEOUT`
沙箱错：502 `UPSTREAM_UNAVAILABLE`

### 6.11.3 取消

```http
POST /v1/skills/parse_docx/invocations/inv_xxx/cancel
```

返回 202 Accepted。

## 6.12 Agent Run 接口

### 6.12.1 创建会话

```http
POST /v1/agents/{aid}/sessions
Content-Type: application/json

{
  "agent_version": "1.2.0",
  "metadata": {}
}
```

响应：

```
HTTP/1.1 201 Created
Location: /v1/sessions/ses_xxx
Content-Type: application/json

{
  "data": {
    "session_id": "ses_xxx",
    "agent_id": "agt_xxx",
    "agent_version": "1.2.0",
    "status": "open",
    "created_at": "2026-09-19T10:00:00Z"
  }
}
```

### 6.12.2 发起 turn（异步）

```http
POST /v1/sessions/ses_xxx/turn
Content-Type: application/json

{
  "content": "查一下本周销售数据"
}
```

响应：

```
HTTP/1.1 202 Accepted
Location: /v1/sessions/ses_xxx/turns/trn_xxx

{
  "data": {
    "turn_id": "trn_xxx",
    "status": "running",
    "stream_url": "/v1/sessions/ses_xxx/turn/trn_xxx/stream"
  }
}
```

### 6.12.3 发起 turn（流式）

```http
POST /v1/sessions/ses_xxx/turn/stream
Accept: text/event-stream
Content-Type: application/json

{ "content": "..." }
```

直接返回 `text/event-stream`，事件序列见 6.8。

### 6.12.4 deny 场景

```
HTTP/1.1 403 Forbidden

{
  "error": {
    "code": "ACTION_DENIED",
    "message": "...",
    "details": { "policy_id": "pol_xxx" }
  }
}
```

## 6.15 幂等性

| 操作 | 幂等键 | 行为 |
|---|---|---|
| 创建会话 | `X-Request-Id` | 重复请求返回同一 session_id |
| 发起 turn | `X-Request-Id` | 重复请求返回同一 turn_id |
| 写 memory | `X-Request-Id` | 重复请求幂等 |
| Tool 调用 | `X-Request-Id` | 同上 |
| Approval | 不支持幂等 | 重复 approve/deny → 409 |

## 6.16 限流维度

| 维度 | 限流键 | 默认值 |
|---|---|---|
| 全局 | `tenant_id` | 10000 req/min |
| 单会话 | `session_id` | 60 turn/min |
| Tool 调用 | `tenant_id + tool_name` | 1000 call/min |
| Skill 调用 | `tenant_id + skill_id` | 100 invoke/min |
| Memory 写 | `tenant_id` | 500 write/min |
| Memory 检索 | `tenant_id` | 2000 search/min |

超限 → 429 + `Retry-After`。

## 6.17 版本与兼容

- 路径前缀 `/v1/`；不删除旧版本
- 新增字段允许；删除字段需先标 deprecated
- 状态码降级视为破坏性变更（见 [10-测试与CI.md 第 10.6 节](10-测试与CI.md) 契约测试）

## 6.18 反模式

| 反例 | 修正 |
|---|---|
| 全部返回 200 + `success: false` | 用 4xx/5xx + envelope |
| 创建资源不返回 Location | 201 必须带 Location |
| SSE 不带 `X-Accel-Buffering: no` | 网关会缓冲 |
| 跨租户数据不隔离 | ORM 自动注入 tenant_id |
| 错误响应不带 trace_id | 强制注入 |
| 限流不带 Retry-After | 必带 |
| Mock token 入生产 | CI 检查 + 启动 warn |
| API Key 在 URL 中 | 只在 header |
