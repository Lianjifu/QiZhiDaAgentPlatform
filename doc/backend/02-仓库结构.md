## 2.3 `libs/*` 共享内核（10 个包）

| 包 | 路径 | 职责 |
|---|---|---|
| `kernel` | `libs/kernel/src/qzdap_kernel/` | `Principal` / `TenantContext` / `WorkspaceContext` / `contextvars` |
| `auth` | `libs/auth/src/qzdap_auth/` | JWT 签发 / 校验 / `APIKeyGuard` / `JWTGuardMiddleware` |
| `observability` | `libs/observability/src/qzdap_observability/` | structlog / OTel / Prometheus / trace_id |
| `persistence` | `libs/persistence/src/qzdap_persistence/` | `Base` / `SessionFactory` / `UnitOfWork` |
| `messaging` | `libs/messaging/src/qzdap_messaging/` | `EventBus` 协议 + `InProcessBus` / `RedisStreamBus` |
| `http` | `libs/http/src/qzdap_http/` | 中间件 / 错误 envelope / 健康检查 / 限流 |
| `schema` | `libs/schema/src/qzdap_schema/` | 跨模块共享 Pydantic DTO / ID 类型 |
| `llm` | `libs/llm/src/qzdap_llm/` | LLM provider 抽象（OpenAI 兼容 + 自定义） |
| `sandbox` | `libs/sandbox/src/qzdap_sandbox/` | 沙箱执行抽象（local / docker / e2b / firecracker） |
| `vector` | `libs/vector/src/qzdap_vector/` | 向量存储抽象（pgvector / milvus） |

每个包结构：

```
libs/<name>/src/<import_root>/
├── __init__.py
├── <submodules>.py
└── py.typed           # PEP 561 类型标记
```

`libs` 共同约束（`libs` 不允许 import 任何 `modules`）：

```ini
# .importlinter.ini
[importlinter:contract:no-business-in-libs]
type = forbidden
source_modules = libs.*
forbidden_modules = modules.*
```

## 2.4 `modules/*` 14 个能力模块

### 2.4.1 命名与职责

| 模块 | 路径 | 职责 | 主要领域对象 |
|---|---|---|---|
| **identity** | `modules/identity/` | 租户、用户、工作区、角色、API Key | Tenant / User / Workspace / ApiKey |
| **agent_factory** | `modules/agent_factory/` | Agent 定义、版本、模板、发布 | AgentTemplate / AgentVersion / Release |
| **agent_runtime** | `modules/agent_runtime/` | Agent 实例化、运行、会话、上下文 | Session / Turn / Context / Message |
| **orchestration** | `modules/orchestration/` | 多 Agent / 流程 / 任务编排 | Plan / Step / WorkflowRun |
| **skill** | `modules/skill/` | 技能包注册、安装、调用、RunToken | SkillPackage / SkillInstall / SkillInvocation |
| **tool** | `modules/tool/` | 工具注册、协议（MCP / OpenAPI / 自定义） | Tool / ToolCall / ToolResult |
| **knowledge** | `modules/knowledge/` | 知识包、向量化、检索、注入 | KnowledgePackage / KnowledgeAsset / Retrieval |
| **model** | `modules/model/` | 模型注册、凭据、路由、配额 | Model / ModelCredential / RoutingPolicy |
| **memory** | `modules/memory/` | 长期记忆、撤销、归档 | MemoryEntry / MemoryScope |
| **channel** | `modules/channel/` | 渠道适配（飞书 / 钉钉 / 企微 / Web） | Channel / ChannelDelivery |
| **governance** | `modules/governance/` | 策略、审批、配额、审计订阅 | PolicyRule / Approval / Quota |
| **observability_module** | `modules/observability_module/` | trace / metrics / log / cost / quality 业务埋点 | RunRecord / CostRecord / QualityScore |
| **evaluation** | `modules/evaluation/` | 评测数据集、评分、门禁 | EvalDataset / EvalRun / EvalScore |
| **platform** | `modules/platform/` | 平台级设置、计费、扩展 | Plan / Subscription / Extension |

> ⚠️ `observability_module` 命名是为了避免与 `libs/observability` 同名冲突。
> 也可考虑改名为 `observe` 或 `audit_trail`，但为表意清晰首选 `_module` 后缀。

## 2.5 `composition/qzdap_app/` 组合根

```
composition/qzdap_app/src/qzdap/composition/
├── __init__.py
├── main.py                # create_app() 工厂
├── lifespan.py            # 启动 / 关闭钩子
├── container.py           # DI 容器装配
├── settings.py            # 强类型 Settings
├── ensure.py              # 启动 ensure（建通用 Agent / 通用 Skill）
└── middleware.py          # 跨切中间件聚合
```

`create_app()` 工厂：

```python
# composition/qzdap_app/src/qzdap/composition/main.py
from fastapi import FastAPI
from libs.http import install_default_middleware
from .container import build_container
from .lifespan import lifespan


def create_app() -> FastAPI:
    container = build_container()
    app = FastAPI(
        title="Enterprise-Agent-OS",
        version="0.1.0",
        lifespan=lifespan(container),
        docs_url="/docs",
    )
    install_default_middleware(app, container)
    mount_module_routers(app, container)
    mount_health_routers(app, container)
    return app
```

## 2.7 `runtimes/*` 远程 Runtime

需要独立部署的能力进程（沙箱隔离、可独立扩缩容）：

| Runtime | 端口 | 职责 |
|---|---|---|
| `qzdap_skill_runtime` | 8093 | 沙箱内执行 Skill；返回产物 |
| `qzdap_tool_runtime` | 8094 | MCP / OpenAPI 工具适配 |
| `qzdap_embedding_runtime` | 8095 | 文本向量化（统一管理 API Key） |

每个 runtime 与主 app 通过 HTTP/RPC 通信；由 `composition/qzdap_app/container.py` 选择注入：
- `local`：app 进程内执行（开发）
- `remote`：调用 runtime（生产）

## 2.8 命名规范

| 类别 | 规范 | 示例 |
|---|---|---|
| **包名** | snake_case | `agent_runtime` |
| **模块名** | snake_case | `session_repo` |
| **类名** | PascalCase | `SessionService` |
| **函数 / 方法** | snake_case | `create_session` |
| **常量** | UPPER_SNAKE | `MAX_TOKENS` |
| **事件** | 过去时 PascalCase | `SessionStarted` `ToolInvoked` |
| **错误** | PascalCase + Error 后缀 | `ActionDeniedError` |
| **端口** | PascalCase + 行为名词 | `LLMPort` `ToolPort` |
| **环境变量** | `QZDAP_` 前缀 + UPPER_SNAKE | `QZDAP_TENANT_ID` |
| **HTTP 路径** | `/v1/<resource>` | `/v1/sessions/{sid}/turn` |
| **ID 类型** | PascalCase + Id 后缀 | `SessionId` `TurnId` |
| **ORM 模型** | PascalCase + Orm 后缀（私有） | `SessionOrm` |

## 2.10 依赖矩阵

`import-linter` 配置关键约束（完整版见 [10-测试与CI.md](10-测试与CI.md)）：

```ini
# 起步四模块可互相依赖（端口），其他模块严格隔离
[importlinter:contract:layered-modules]
type = layers
layers =
    modules.identity
    modules.governance | modules.observability_module
    modules.model
    modules.agent_runtime
    modules.skill | modules.tool | modules.memory
    modules.knowledge | modules.orchestration | modules.channel
    modules.agent_factory | modules.evaluation
    modules.platform
```

每个模块可向下依赖（端口），不可向上依赖。

## 2.11 与原模板的差异（速查）

| 项 | 原模板 | 本项目 |
|---|---|---|
| 模块数 | 8 | 14 |
| 起步范围 | 全模块渐进 | 4 模块闭环 + 治理 / 观测 |
| 多租户 | 仅 Workspace | Tenant + Workspace |
| Agent 抽象 | 隐式 | 独立 `agent_runtime` + `agent_factory` |
| 模型 | 隐藏在 cap | 独立 `model` 模块 |
| 知识 / 渠道 | 隐藏在 cap | 独立 `knowledge` / `channel` |
| 编排 | workflow | `orchestration`（可调其他 Agent） |
| 治理 | policy / audit 分离 | 合并 `governance`（审计是订阅者） |
| libs | 9 包 | 10 包（新增 `llm` `sandbox` `vector`） |
| Runtime | skill / agent / rag | skill / tool / embedding（tool 独立） |
