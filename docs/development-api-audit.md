# 开发模式真实 API 审查

日期：2026-10-14

## 数据规则

- 业务环境只有演示和开发。显式指定 development 时，旧 Mock/Demo 开关不能覆盖它。
- 演示环境在入口注入前端 Mock；开发环境不注入，API 客户端不提供失败回退入口。
- 查询返回空数组或无内容时保持为空；查询失败显示错误，不再继续显示查询缓存中的旧成功结果。
- 创建、编辑、删除、收藏、批量操作、导入和运行请求必须交给后端。只有成功响应才能提示成功、关闭提交弹窗或刷新列表。
- 编辑草稿、搜索筛选、选择项和主题属于界面状态；本地状态不代表业务数据已保存。

## 审查范围及修复

| 范围 | 修复内容 |
| --- | --- |
| API 客户端、查询层 | 删除读请求 Mock 回退；HTTP 200 的失败 envelope 同样抛错；支持 204；查询错误不显示旧数据；关闭跨工作空间 placeholder；统一显示查询和写入错误 |
| 智能体、技能、知识、记忆、工作流 | 列表、详情及关联数据通过 API；移除智能体列表默认 Mock；记忆关联智能体不再从示例数据或不成立的关系推算；知识源同步发请求；MCP 探测仅演示环境允许模拟 |
| 评测、回归、反馈 | 删除本地数组 CRUD；详情保存、运行、批量操作、规则开关及删除发请求；导入提交原始文件内容；反馈回复和历史通过 API |
| 运行、审计、指标 | 删除本地修改假成功；上下文、日志、处置响应通过 API；指标导出真正生成文件；运行筛选从真实列表生成选项并应用 |
| 模型、配额、渠道 | 删除请求前的成功提示；批量操作等服务器成功；导入不再按数量构造假记录 |
| 用户任务、智能体、技能、知识、自动化、团队 | 移除直接读取 mockTasks；收藏、任务操作、邀请发请求；工作流历史来自后端；知识检索展示后端命中的引用；选择项存储隔离演示与开发 |
| 首页、个人洞察、平台及账号设置 | 移除固定业务任务、趋势、成果、成员和审计行；查询、保存接入真实 API；缺失功能不提示已成功 |
| Copilot | 移除错误时的模拟回复和演示会话；显示列表、详情、流事件及审批错误；开发模式不显示虚构文件和终端；附件上传必须成功返回附件 ID |
| 后端执行与总览 | 基线评测、版本比较、智能体导出尚未实现时明确失败；不生成 100% 通过率及虚构运行记录；总览不补空库趋势、健康服务或模型伪装的热门智能体 |
| 后端供应商 | 开发模式不调用 Mock LLM 或零向量嵌入；未配置真实供应商时调用失败；数据库管理接口仍可启动；test/ci 保留测试替身 |

此外修正了智能体批量删除路由被动态 ID 路由遮挡的问题，并为知识检索新增正式 `/api/catalog/knowledge/ask` 路由，保留旧路径兼容。

## 后端尚未完成的能力

本次修复数据来源与失败行为，没有将所有缺失的后台能力实现为可用功能。根据当前路由代码，以下请求仍可能返回 404/405/422；显式未实现的智能体能力返回 501。它们不再修改本地列表或报告成功：

- 评测、回归、反馈的部分更新、删除、批量、运行与导入接口。
- 审计处置与详情日志、运行会话上下文和日志、预算历史、反馈历史和回复。
- 指标看板更新、批量操作、阈值规则更新，以及供应商健康检查。
- 模型、配额和渠道批量文件导入。
- 工作空间成员及邀请、个人设置、个人洞察、平台设置审计。
- 记忆策略／L3 条目关联智能体查询，智能体审计和版本回滚。
- MCP 能力发现与 Copilot 附件上传。

智能体评测、版本比较及导出明确返回未实现错误。自动化“运行”当前后台仅保存使用记录，界面相应标明“使用记录已保存”，不宣称执行了工作流。

真实模型和嵌入供应商需要配置后才能调用。已有数据库中历史测试数据不在本次自动清理范围内；本次不会删除或重新灌入数据库数据。

## 验证边界

- 前端类型检查及 Vite 构建。
- 环境与 API 客户端定向验证：空列表、204、网络失败、HTTP 错误、失败 envelope 和失败写请求。
- 后端定向验证：目录 CRUD、不写入伪造评测、总览空数据、开发模式拒绝模拟供应商。
- Git 差异格式检查。

上述验证覆盖统一规则与变更点，没有逐页操作全部按钮，也没有对所有接口做真实数据库端到端验收。缺失路由清单来自代码审查。
